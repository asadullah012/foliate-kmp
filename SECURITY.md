# Security Policy

The **foliate-kmp** team takes the security of our library and users seriously.

## Supported Versions

We provide security updates for the current active release line:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have discovered a security vulnerability in `foliate-kmp` (such as a WebView sandbox escape, JavaScript bridge injection, or path traversal vulnerability), please report it privately:

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   Go to the [Security Advisories](https://github.com/asadullah012/foliate-kmp/security/advisories) tab of this repository and click **"Report a vulnerability"**.

2. **Email**:
   If private reporting is unavailable, email the maintainer directly at `asadullah.galib.dev@gmail.com` (or through the maintainer's GitHub profile: [@asadullah012](https://github.com/asadullah012)) with:
   - A description of the vulnerability.
   - Steps to reproduce or a minimal proof of concept (PoC).
   - The impact of the vulnerability.

## What to Expect

- **Acknowledgment**: You will receive an acknowledgment of your report within 48 hours.
- **Triage & Assessment**: We will verify and assess the vulnerability severity.
- **Fix & Disclosure**: We will work on a patch and coordinate a disclosure timeline before releasing a security patch and public advisory.
